# 🌿 WasteWise AI

> *Fix the attitude → Fix the waste → Fix the planet*

An AI-powered waste segregation and mismanagement 
reporting app for campuses — built to solve the 
real problem of waste mismanagement through 
awareness and technology.

---

## 🚨 The Problem

 University has dustbins. It has a canteen. 
It has water stations. Yet waste mismanagement 
persists — because the problem was never about 
infrastructure. It's about awareness.

- 🧠 Students don't know which waste goes where
- 📵 No system to report mismanagement
- ❌ Admin unaware of ground-level issues

---

## 💡 The Solution — 2 Core Features

### Feature 1 — Waste Segregation AI 📸
Student clicks photo of waste item → AI breaks it 
down component by component → tells exactly which 
bin each part goes into

**Example — Coffee Cup:**
- Cup body → ♻️ Biodegradable bin
- Plastic lid → 🚯 Non-biodegradable bin  
- Plastic straw → 🚯 Non-biodegradable bin

### Feature 2 — Mismanagement Reporting 🚨
Student spots mismanagement → clicks photo → 
auto report with location + timestamp sent 
directly to campus admin → action taken
